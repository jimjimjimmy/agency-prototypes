## What this repo is

Public, viewable agency outputs only. This is not internal process, and it is not a client site yet.

Organization, keep it clean:
- fq-prototypes: FloQast work only
- projects: personal work, portfolio pieces, apps, and experiments
- typographic-agency-os: private, internal agency process, single source of truth for how the agency works
- agency-prototypes: public, viewable agency outputs only, this repo

Hosting: GitHub Pages is interim hosting for prototypes. The final agency site will be hosted at Bluehost, where Jimmy sites live. Prototypes must use relative paths for assets, images, and internal links, so they stay portable across hosts.

Deliverable rule: viewable applications, not code links. Jimmy cannot use code to buy pens, he needs the application.

## Standing rules for this repo

- Never use em dashes.
- Say "AI enhanced", never "AI powered".
- No public post or publish without Jimmy yes, except @design.secret.agent, which is a separate account and is not in this repo.
- Flag whether a recommended tool or service requires a subscription. Jimmy dislikes paying for subscriptions.
- Restraint is a trained skill. Good designers take things away. Do not add outlines around elements that already sit in a container.
- Competitive analysis goes before design. Research the exact flow across real services, write pros and cons, then improve on them.
- Think, research, think, then do. Research online for the question or similar questions before doing the work. Knowledge must be written down so a new agent can learn it, not held tacitly.
- Never put credentials, tokens, passwords, or API keys in files, chat, or commits. Never copy a credential-filled prompt into a repo.
- Flow Lab Week 1 is sign-in, mobile only, staple. brand. Do not publish MUJI copy or MUJI product images publicly. Those were cleared for internal training only. Use staple. original copy for public outputs.

## How to work here

- Build standalone, portable HTML files with relative paths.
- Keep each prototype in its own folder, with a clear name.
- Update the root index.html gallery entry when you add a prototype, so the gallery stays current.
- Report back in #ai-workflows with what you built, where it is hosted, and what is still open. A reading reaction alone is not a reply. Important things go top-level, never in threads.
